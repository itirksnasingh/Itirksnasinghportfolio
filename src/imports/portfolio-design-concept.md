Design a modern, minimalist yet atmospheric personal portfolio website inspired by surreal glowing flowers, dreamlike botanical worlds, and bioluminescent night gardens. The design should feel magical, elegant, and slightly futuristic, while still maintaining minimalism and clarity so the content (projects, cards, text) remains the focus.

The website should not feel cluttered. Decorative elements should appear subtle, intentional, and spaced out, used as section accents rather than overwhelming visuals.

The design inspiration comes from the attached reference images featuring:

glowing neon flowers in dark environments

surreal botanical forms

bioluminescent plants

fantasy night gardens

colorful dreamlike floral compositions

Use these images as the primary style inspiration for color, shapes, lighting, and atmosphere.

Visual Style

Create a dark atmospheric theme.

Background:

deep black / dark purple / midnight gradient

subtle glow and vignette

minimal or no patterns

Flowers and botanical elements:

bioluminescent

glowing edges

soft gradients

surreal shapes

slightly abstract petals

Lighting:

soft glowing particles

floating pollen

firefly-like dots

Motion should feel slow, organic, and dreamy.

Color Palette

Use colors derived from the reference images.

Primary accents:

pink (all shades)

yellow (golden yellow to warm orange-yellow)

Secondary accents:

coral

peach

magenta

orange

glowing neon yellow

Supporting colors:

teal

turquoise

deep greens

soft purples

Use gradients frequently to simulate glowing petals.

Example gradients:

pink → yellow

orange → coral

magenta → soft gold

teal → turquoise

The colors should feel luminous and soft, not flat.

Overall Layout

The website should contain 7 sections.

Sections should feel connected visually but each one should have its own botanical accent.

Use large spacing and clean typography so the interface remains minimal.

Decorative flowers should appear mainly:

corners

bottom edges

subtle overlays

section dividers

Never place too many flowers in one area.

Motion & Interaction

Include subtle motion ideas for the design.

Examples:

• Flowers slowly swaying like plants in wind
• Petals blooming when section appears
• Floating glowing particles
• Firefly-like lights moving upward
• Slight parallax movement on scroll
• Flowers growing from bottom of screen
• Small glowing pollen drifting

Animations should feel:

slow

organic

smooth

calm

Avoid fast or distracting animation.

Section Structure

Design seven sections with the following concepts.

1 — Hero Section

Theme: Blooming Garden Entrance

Elements:

dark background

glowing flower stems growing from the bottom of the screen

floating particles in background

Center content:
Name
Title
Short tagline
Call-to-action button

Scroll effect:
Flowers gently sway and move downward slightly with parallax.

This section should feel like entering a magical garden at night.

2 — About Section

Theme: Calm Botanical Space

Minimal layout with large whitespace.

Add only:

1–2 glowing flower stems in corners

small floating particles

Content:

short biography

personality traits

creative philosophy

This section should feel calm and clean.

3 — Skills Section

Theme: Bioluminescent Plant Network

Skills appear like glowing plant stems.

Each skill node can look like:

a small flower

a glowing bud

or a bioluminescent node

When hovered:

petals open

glow intensifies

Use pink, yellow, teal gradients.

4 — Projects Section

Theme: Floating Garden Cards

Projects appear as minimal cards floating above a dark garden.

Cards should include:

project title

short description

tags

preview image

Hover effects:

card lifts slightly

small flowers bloom near card edges

glow effect

Keep the layout clean.

5 — Experience / Journey Section

Theme: Growing Vine Timeline

A vertical timeline shaped like a plant vine.

Each milestone appears as:

glowing node

blooming flower

Scroll animation concept:
The vine slowly grows downward as user scrolls.

6 — Creative / Interests Section

Theme: Wildflower Field

Slightly more colorful.

Include:

diverse flower shapes

pastel petals

glowing pollen particles

But still keep spacing and minimalism.

This section represents personality and creativity.

7 — Contact Section

Theme: Quiet Night Garden

Very calm ending scene.

Minimal flowers like glowing lanterns.

Include:

contact links

email

social icons

Subtle glow animation on flowers.

The section should feel peaceful and atmospheric.

Typography

Use modern clean fonts.

Heading style:

elegant

slightly futuristic

Body text:

simple

readable

Maintain strong contrast against dark background.

UI Style

Use:

glassmorphism or soft glow cards

rounded corners

minimal icons

smooth transitions

The interface should remain clean and modern while the background adds atmosphere.

Overall Design Goal

The website should feel like a minimal digital garden at night.

It should communicate:

creativity

curiosity

calm intelligence

artistic technical personality

The flowers and glowing elements should support the story of growth and exploration, not overpower the content.

The final result should feel:

dreamlike
minimal
elegant
interactive
cohesive
